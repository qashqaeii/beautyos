# Phase 5 — salon automation (first increment)
The phase-4 marketing engine remains the campaign entrypoint. New per-salon automation policy is opt-in, disabled by default. Confirmed appointment reminders within 24h (more than 5 min remaining), actual Jalali birthday, and winback after 60 days using open follow-up cycles are prepared in a durable queue with source-level uniqueness. Archived customers, missing phone, changed/cancelled bookings, disabled policy, expired intents and withdrawn marketing consent are suppressed on refresh. No reactivation of skipped intents within the same source event.
Manager-only settings and preview are linked from marketing. Run `python manage.py prepare_automation` manually or every 15 minutes with an installed deployment scheduler. This command does not send messages and no production scheduler has been changed. No actual SMS provider, confirmation/cancellation notification, scheduled campaign dispatch, cross-campaign throttling, or delivery/conversion metrics yet. Before enabling transport, recheck suppression at claim time, add provider idempotency and explicit unknown-delivery reconciliation.
